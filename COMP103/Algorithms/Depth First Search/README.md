# Depth First Search and Breadth-First Search
This is Depth-First, and Breadth-First Search coded recursively for all, DFS, and using loops for BFS.

To change the search type, change the method.

**DFS Methods available:**
* `printAllPre()` - Visit the root node, then traversing sub-trees from left to right.
* `printAllPost()` - Traverse the sub-trees from left to right, then visit the root node.
* `printAllInOrder()` - Traverse the left sub-trees, then visit the root node, then traverse right sub-trees.

**BFS Methods available:**
* `printLevelOrder()` - Visit each node at each level of the tree from top (root) to bottom and left to right.
